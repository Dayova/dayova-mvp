# Hint location comparison, examples v1

Design brief: the job is to preserve actual exam conditions and special instructions without distracting from topic selection. Hierarchy: topics first, optional conditions second, continue to materials third. Continue remains the primary action; conditions are never a mandatory step. A single multiline editor accepts arbitrary instructions and offers explicit contextual example buttons beneath it. A second search/commit field would create an uncommitted draft that can be lost on back; free typing therefore edits the saved text directly. Both variants use this identical editor. Only its placement differs.

Inline is the default. Extraansicht opens a full-screen subview of the existing setup screen; it keeps the same progress step and state owner, avoiding route-parameter copies of sensitive free text. Header/hardware Back and “Zurück zu den Themen” retain edits and selection, without advancing to materials. The topics page shows a three-line preview and an edit action. Closing still uses the existing save/pause contract. This is an agreed comparison, not a validated winner.

## Moderator entry

In the non-production native app, open **Einstellungen → Hinweisvergleich (Test)**, or `dayova://hint-validation`. Choose **Inline: neue Prüfung** / **Extraansicht: neue Prüfung** before handing over the phone. The ordinary subject/date/exam flow then runs unchanged. **Entwurf öffnen** instead opens the plan list; choose the appropriate synthetic/student draft, return from material to topics. The assignment is stored locally, frozen per mounted setup flow, and survives process restarts. All drafts on this device use this assignment on their next mount; it is not a server-side student or plan assignment. Never switch it during a session. No student-facing toggle and no automatic data deletion. Start a new exam for the second case. Restore Inline after the study. Production application IDs ignore the preference and redirect the moderator route home; auth/access gates remain active.

Examples v1 are deterministic and local: math (including Mathe LK) offers no calculator / show working, geometry/vector topics additionally label sketches; German offers textual evidence with line numbers / covered chapters; accounting context with relevant subject/topic offers account-numbered entries / show calculation. Physics/chemistry, biology and supported languages have small reviewed sets. Unknown custom subjects receive neutral instructions and no guessed examples. Combined known subjects use the existing subject resolver; at most three examples. Subject identity is unchanged. Examples make no claim about the teacher's actual requirements, are never preselected, and are only appended on tap. Existing text is preserved verbatim; no splitting or reinterpretation of conditional instructions. Repeating an identical normalized line does not duplicate it. No networking, LLM call or new raw-text analytics.
